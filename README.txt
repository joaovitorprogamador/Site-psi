# Site de Psicólogo — versão profissional

Arquivos:
- index.html — estrutura da página
- style.css — todo o visual/responsividade
- script.js — menu mobile e rolagem suave

## Personalização rápida

No `index.html`, troque:
- `Seu Nome`
- `CRP 00/00000`
- número do WhatsApp nos links `wa.me`
- textos de formação/atendimento

O bloco `.photo-placeholder` e `.office-placeholder` é um placeholder criado em CSS. Para usar fotos reais, substitua esses blocos por `<img>` ou coloque suas imagens no projeto.

O layout foi pensado para transmitir acolhimento, profissionalismo e percepção de valor, com CTA claro para agendamento.
